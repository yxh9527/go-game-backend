# 比赛后台反向代理

比赛后台页面由独立的 `match` 服务提供。前端请求 `/gogame-match/admin`，管理 API 也使用同一个 `/gogame-match/` 前缀。开发环境的 Vue proxy 已转发至 `127.0.0.1:11040`；生产环境必须在实际部署的 HTTP 网关中添加对应规则，Vue 的 `devServer.proxy` 不会进入生产构建。

Nginx 示例（将上游地址改为 match 服务从网关可达的地址）：

```nginx
location ^~ /gogame-match/ {
    proxy_pass http://127.0.0.1:11040/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

`proxy_pass` 末尾的 `/` 会去掉 `/gogame-match/` 前缀，使 `/gogame-match/admin` 转发为 match 服务的 `/admin`，并使后续 `/v1/...` 管理 API 转发到 `/admin/v1/...`。该规则须放在前端 SPA 的通用回退规则之前；否则前端会把 iframe 请求当作页面路由并返回后台首页。
